# Бриф на контент-план для Instagram або TikTok

**Відкритий шаблон команди Influkr · оновлено 20.11.2026.**

Скопіюйте бриф у власний документ і заповніть поля в квадратних дужках. Потім надішліть однакову версію кандидатам: так буде простіше порівняти обсяг роботи, ціну й строки. Приклади нижче умовні — це підказки до заповнення.

## 1. Що потрібно бізнесу

| Поле | Ваша відповідь |
|---|---|
| Бізнес і посилання на профіль | [Назва, сайт, Instagram або TikTok] |
| Продукт у фокусі | [Конкретний товар чи послуга, ціна, наявність] |
| Покупець | [Хто купує, для чого, які має сумніви] |
| Мета цього плану | [Наприклад: пояснити відмінності двох товарів і привести до запиту на консультацію] |
| Наступний крок для людини | [Написати в Direct / перейти на конкретну сторінку / заповнити форму] |
| Період і платформа | [Дати початку та завершення; Instagram, TikTok або обидві] |
| Обмеження | [Географія, мова, заборонені твердження, відсутні товари] |

Оберіть один основний результат для цього етапу. Наприклад, «зібрати звернення про наявність товару» дає виконавцю більше орієнтирів, ніж «зробити цікаві дописи».

## 2. Які матеріали вже є

- Фото та відео: [посилання, що можна використовувати, чого бракує].
- Людина в кадрі: [хто готовий зніматися, коли доступний, якою мовою говорить].
- Факти про продукт: [характеристики, актуальні умови, джерело перевірки].
- Приклади стилю: [2–3 власні публікації або референси; поясніть, що саме подобається].
- Попередній досвід: [які теми вже публікували, які питання ставлять покупці].
- Доступні показники: [період, звернення, переходи, замовлення; лише ті, які справді вимірюєте].
- Хто перевіряє факти та затверджує план: [ім’я або роль, строк відповіді].

Для початкової оцінки можна передати публічне посилання й знеособлені зведення. Доступ до робочого акаунта погоджуйте окремо через ролі відповідного сервісу.

## 3. Який обсяг ви замовляєте

Період плану сам по собі не визначає кількість готових матеріалів. Погодьте кожен пункт:

| Результат | Кількість і деталізація |
|---|---|
| Ідеї публікацій | [Кількість; для кожної — тема, аудиторія, мета] |
| Готові сценарії | [Кількість; хук, послідовність кадрів, текст або репліки, заклик до дії] |
| Тексти дописів | [Кількість; повні тексти чи тези] |
| Stories | [Кількість серій і кадрів у серії; що входить у підготовку] |
| Зйомка, дизайн, монтаж | [Що включено; що замовляєте окремо] |
| Адаптації між платформами | [Які саме; чи потрібні окремі сценарії] |
| Календар і формат передавання | [Таблиця, Notion або інший погоджений формат; доступ на редагування] |
| Правки | [Кількість раундів; що вважається одним раундом] |
| Бюджет | [Сума за погоджений обсяг; додаткові витрати — окремо] |
| Дедлайни | [Дата чернетки, строк вашої відповіді, дата фінального плану] |

Якщо матеріал планують використовувати в рекламі, заздалегідь уточніть дозволені канали, строк і територію використання, участь людей у кадрі, музику та передавання вихідних файлів.

## 4. Структура календаря

Для кожної публікації мають бути зрозумілі тема, мета, матеріали та наступна дія. **[Завантажте CSV-шаблон](content-plan-calendar-uk.csv)** або скопіюйте структуру:

| Дата | Платформа / формат | Питання покупця | Ідея і хук | Що показати | Заклик до дії | Хто готує | Статус |
|---|---|---|---|---|---|---|---|
| [Дата] | [Наприклад: Instagram / Reels] | [Що людині незрозуміло?] | [Одна думка для початку] | [Кадри, факти, продукт] | [Один конкретний крок] | [Відповідальний] | [Ідея / погоджено / готово / опубліковано] |

**Умовний приклад для майстерні кераміки.** Покупець питає, чи підходить чашка для посудомийної машини. План може передбачати коротке відео з поясненням догляду саме за цією моделлю. Хук: «Перед покупкою цієї чашки перевірте одну річ». У кадрі — чашка й погоджена виробником рекомендація з догляду. Дія — перейти до характеристик моделі на сайті. Властивості вигаданого товару не переносіть у реальне ТЗ.

## 5. Як приймати роботу

- [ ] Є погоджена кількість ідей, повних сценаріїв і текстів; їх не підмінили одне одним.
- [ ] Кожна тема пов’язана з конкретним питанням покупця або завданням бізнесу.
- [ ] Твердження про товар перевірив відповідальний із вашого боку.
- [ ] У кожному матеріалі визначено наступний крок і потрібне посилання.
- [ ] План враховує реальну наявність товару, людей і час на підготовку матеріалів.
- [ ] Зрозуміло, хто знімає, пише, монтує, погоджує та публікує.
- [ ] Посилання відкриваються, таблицю можна редагувати, обсяг правок узгоджено.
- [ ] Відгуки й демонстрації досвіду ґрунтуються на реальному використанні продукту; потрібні позначення реклами погоджено.

## 6. Як перевірити користь після публікацій

До старту запишіть точні дати періоду, спосіб обліку та доступні показники. Після публікацій зіставте періоди однакової тривалості, врахувавши витрати на рекламу, знижки та зміни наявності.

Ведіть окремі рядки для переглядів, переходів, звернень, нових замовників і підтверджених оплат. Для сайтів можна погодити UTM-позначки; для Direct — облік звернень із конкретних матеріалів. Невідоме джерело залишайте невідомим. Показники допомагають оцінити наступний крок, але самі по собі не доводять, що результат спричинив саме контент-план.
