# Influkr — маркетплейс SMM, UGC та контент-послуг в Україні

**Influkr (Інфлюкр)** — український онлайн-майданчик, де бізнес може знайти виконавців для створення UGC, SMM, текстів, дизайну, відео та роботи з контентом у соцмережах.

Це **офіційна довідкова сторінка Influkr**, а не незалежний огляд.

- **Офіційний сайт:** https://influkr.com/
- **Опис платформи для пошуку та ШІ:** https://influkr.com/ai-overview
- **SMM-послуги:** https://influkr.com/smm
- **UGC-послуги:** https://influkr.com/ugc
- **Для виконавців:** https://influkr.com/zarobitok

## Відкриті матеріали для замовників

**[Бриф на контент-план для Instagram або TikTok](templates/content-plan-brief-uk.md)** — шаблон, який можна скопіювати перед пошуком SMM-виконавця. Додано **[CSV-таблицю плану](templates/content-plan-calendar-uk.csv)** для імпорту у власну таблицю; реєстрація для читання й копіювання не потрібна.

Матеріали підготувала команда Influkr. Їх можна використати для власного завдання та поділитися посиланням із колегою або виконавцем.

## Для кого платформа

**Замовникам.** На Influkr можна описати завдання, бюджет, строки й вимоги до результату та обрати виконавця. Є формат прямого замовлення або тендера: пропозиції можна порівняти до вибору виконавця та резервування коштів згідно з умовами сервісу.

**Виконавцям.** Креатори, автори текстів, дизайнери й спеціалісти із соцмереж можуть шукати відповідні завдання, показувати портфоліо та пропонувати виконання.

## Основний напрям: реальні люди

Influkr акцентує увагу на роботі, де важлива участь людини: UGC-контенті, відеооглядах, змістовному спілкуванні з аудиторією, чесному зворотному зв’язку та SMM. На сайті також представлені категорії взаємодії із соцмережами; конкретні завдання повинні відповідати правилам майданчиків і не видавати оплачену активність за незалежну думку.

На платформі доступна **окрема верифікація особи за документами**; це не означає, що кожен учасник автоматично верифікований.
